# Gyro, touchpad, mouse and keyboard

Controls that report movement rather than position have no level to diff, so the level-based model can't carry them as it stands. A uhid virtual pad could present them.

**Why deferred.** Out of scope for an assist tool's first release.

**Would bring it in.** A use for gyro or touchpad assist. One came on 2026-11-23: a hidden pad now has its touchpad and sensor nodes hidden too, so they are lost to a game while a setup runs. For a PlayStation pad that is taken up in [the plan](../plans/motion-and-touch.md); a mouse and a keyboard stay here.
