# Nicknames for pads

Two pads of one model read alike in a list: both are "DualSense Wireless Controller". A name the user gives a pad would tell them apart in the window, the tray, the CLI and a profile's pickers.

**Why deferred.** It needs a field the daemon stores with a known pad and publishes, and an rpc to set it. The window's pads list shows a pad's own name with a short tag from its address meanwhile.

**Would bring it in.** People with several pads of one model find the tags not enough.
