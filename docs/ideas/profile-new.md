# Making a preset profile from the command line

`ctrlassist profile new couch --preset priority --primary <pad> --assist <pad>` would make a preset without writing a file, its flags and completions generated from the schema the daemon serves for the window's form.

**Why deferred.** Profiles go in as files today, and a preset is five lines. The schema's first users are the window and the tray.

**Would bring it in.** People scripting setups ask for it, or the file step proves a hurdle for a first profile.
