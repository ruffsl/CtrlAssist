# The profile tiles' glyphs, carried with the window

A profile's tile shows its arrangement's shape in the desktop theme's glyphs: `kr_combine` for pads joined into one, `split` for a pad shared out, `view-list-text` for a profile written by hand. Those are Breeze's names. A theme without them leaves the tile bare, with only the profile's name beside it. Copies of the three Breeze files carried in the window would give every desktop the same tiles.

**Why deferred.** The window ships no glyphs of its own, so that it looks at home under any theme, and carrying Breeze's means carrying its license (LGPL) in the bundle the packages ship. The tiles drew shapes of the window's own before, which matched no theme's line work.

**Would bring it in.** Reports of bare tiles from desktops that don't have Breeze's icons installed, GNOME's first.
